# キープオンショップ AI商品検索チャットウィジェット 運用手順

このドキュメントは、専門的な知識がなくても設置・更新作業ができるように書いています。
わからない箇所があれば、遠慮なく開発担当に聞いてください。

---

## 1. カラーミーへの設置手順

ウィジェットは「1行のタグを貼るだけ」で表示されます。以下のどちらか一方の方法で設置してください（両方やる必要はありません）。

### 方法A: 検索エンジン対策の設定を使う（おすすめ）

1. カラーミーの管理画面にログインする
2. 左メニューの「ショップ作成」→「デザイン設定」→「検索エンジン対策」→
   「headタグ内フリースペース設定」を開く
3. 以下のタグをテキストエリアに貼り付けて保存する

   ```html
   <script src="https://{vercelドメイン}/shop-widget/widget.js" defer></script>
   ```

   `{vercelドメイン}` の部分は、実際にデプロイしたVercelのドメイン
   （例: `keepon-shop-widget.vercel.app` や独自ドメイン設定時はそのドメイン）に置き換えてください。

### 方法B: 共通HTML編集を使う

「デザイン設定 > HTML/CSS編集」内の共通ヘッダー・フッターに同じタグを貼っても構いません。
方法Aと方法Bはどちらか一方だけで十分です。

### 設置確認

サイトを開いて、画面右下（チャネルトークの緑ボタンの真上）に赤いオレンジ色の丸いボタンが
表示されていれば設置成功です。ボタンを押すとチャットパネルが開きます。

## 2. 商品データの更新手順（月1回想定・所要10分）

商品を追加・変更したら、以下の手順でAIが検索に使うデータを更新してください。

1. カラーミー管理画面 →「商品管理」→「商品データ一括登録/更新」→
   「CSVダウンロード」で全商品CSVを出力する（ファイルは`Downloads`フォルダなどに保存される）
2. パソコンでターミナル（Mac: ターミナル.app / Windows: PowerShellやGit Bash）を開き、
   このプロジェクトのフォルダに移動する
3. 次のコマンドを実行する（ダウンロードしたCSVのパスに合わせて書き換える）

   ```bash
   npx tsx scripts/index-products.ts ~/Downloads/ダウンロードしたファイル名.csv
   ```

4. 実行すると次のようなログが流れます。エラーが出ずに `完了: 〇〇件を登録・更新しました。`
   と表示されれば成功です。

   ```
   CSV読み込み中: ...
   全3913件中、掲載対象 3913件（非掲載スキップ 0件）
   100/3913 件処理済み
   200/3913 件処理済み
   ...
   完了: 3913件を登録・更新しました。
   ```

5. 途中でエラーが出た場合は、いったんそのままにして開発担当に画面のログをそのまま送ってください
   （再実行しても安全です。処理済みの商品は上書きされるだけです）。

## 3. 環境変数の一覧と取得場所

このプロジェクトを動かすには、以下の環境変数をVercelの「Settings > Environment Variables」と、
ローカルで作業する場合は `.env.local` ファイル（`.env.example` をコピーして作成）に設定します。

| 変数名 | 取得場所 | 備考 |
| --- | --- | --- |
| `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/apikey) で無料発行 | サーバー専用。フロントには絶対に出さない |
| `SUPABASE_URL` | Supabaseダッシュボード > Project Settings > API | |
| `SUPABASE_SERVICE_ROLE_KEY` | 同上（「service_role」の方のキー） | 強い権限を持つため厳重に管理する |

`.env.local` はGitにコミットしないでください（`.gitignore` に含まれています）。

## 4. うまく動かないときの一次切り分け

### チャットボタンが出ない・パネルが開かない

1. ブラウザで対象ページを開き、「開発者ツール」→「Console」タブを開く
2. 赤いエラーが出ていないか確認する（`[shop-widget]` から始まるログが手がかり）
3. `widget.js` のURL（設置タグの `src`）に直接アクセスしてJSが表示されるか確認する
   （404になっている場合はVercelへのデプロイやドメインの指定を見直す）

### チャットの返信が来ない・エラー文言が出る

1. 開発者ツールの「Network」タブで `shop-chat` へのリクエストを探す
2. ステータスコードを確認する
   - `429`: アクセスが集中しています。少し待って再送してください
   - `403`: 許可されていないサイトから呼び出されています（CORS設定を確認）
   - `500`: サーバー側のエラーです。Vercelのログを確認してください
3. Vercelダッシュボード →対象プロジェクト →「Logs」で `shop-chat error` のログを確認する
   （Gemini/Supabaseの環境変数が正しく設定されているかも合わせて確認）

### 商品データが古い・検索結果がずれている

上記「2. 商品データの更新手順」を実行してください。それでも直らない場合は
Supabaseダッシュボードで `shop_products` テーブルの行数・`updated_at` を確認してください。
